# Книга рецептов

[Открыть книгу](https://sergo-proggger.github.io/recipe-book/)

На iPhone откройте книгу в Safari и выберите «Поделиться» → «На экран Домой». В Chrome на Android используйте «Установить приложение» или «Добавить на главный экран».

Кнопка «Добавить рецепт» открывает редактор. Можно вставить текст целиком с названием на первой строке или выбрать файл. Приложение принимает TXT, MD, фотографии JPG, PNG и WebP, а также книги в PDF. PDF хранится как отдельная запись с оригиналом книги. Несколько текстовых рецептов в одном файле разделяются строкой из трёх дефисов.

Личные рецепты и вложения сохраняются в IndexedDB текущего браузера. Команды в меню книги позволяют скачать и восстановить копию JSON. После первого открытия и загрузки ресурсов приложение работает офлайн.

## Публикация

GitHub Pages публикует корень ветки main. Сборка и внешние сервисы не требуются. Общие рецепты лежат в recipes.js. У каждого рецепта постоянный id, название title, текст body, раздел category, примечание note и время created в миллисекундах. При изменении приложения или набора рецептов увеличьте версию кеша в sw.js.
